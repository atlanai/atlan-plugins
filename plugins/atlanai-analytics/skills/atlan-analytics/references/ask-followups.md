# Follow up on an answer

Offer the propose flow once when an answer has no governed definition or the person corrects
a published metric's number or definition. On a yes, follow [propose mode](propose.md) from
step 1. It previews before writing and never changes a metric itself. Never propose without
asking. A project setup answer with missing released context offers to extend that context;
it does not silently fall back to an ungoverned answer.

When the person asks to share the answer with colleagues, use the core plugin's `atlan-share`
skill to record it and post the hand-off. To keep it without an audience, use
`atlan-record-outputs`. Name the metric or saved query used. Do not send messages without
the required authorization.
