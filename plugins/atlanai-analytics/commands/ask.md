Load this plugin's `analytics-ask` skill with `$ARGUMENTS` as the question (in Claude Code,
the Skill tool's `atlanai-analytics:analytics-ask`). Answer from published Atlan metrics and
saved SQL, or from the context of a build in this folder. With no question, ask for one in
a single line. Do not create a project, eval, agent or registry write to answer.
